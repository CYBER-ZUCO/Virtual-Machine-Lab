# Virtual-Machine-Lab
My hands-on virtual machine lab for learning IT, networking and cybersecurity.

## What is a Virtual Machine?

A virtual machine (VM) is a computer that runs inside another computer. It allows me to practise using different operating systems without changing my main laptop.

## Why I Use Virtual Machines

I use virtual machines to learn and practice IT and cybersecurity skills. They allow me to experiment with operating systems, networking and security tools without affecting my main laptop.


### Software Used

- VMware Workstation

### What I Did

1. Opened VMware workstation and created a new virtual machine.
2. Configured the virtual machine settings, including memory and storage.
3. Allocated storage space for the virtual machine.

## What I Learned

I learned how to create a virtual machine using VMware workstation and configured its memory and storage settings.
